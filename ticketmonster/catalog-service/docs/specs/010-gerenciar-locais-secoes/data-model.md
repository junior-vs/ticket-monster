# Data Model: US-CAT-10 - Venue e Section

## Venue

**Table**: `catalog.venue`

**Role**: Aggregate root for physical venues.

| Field | Type | Rules |
|---|---|---|
| `id` | UUID | Primary key, generated by PostgreSQL via `gen_random_uuid()` |
| `name` | varchar(255) | Required, globally unique, trimmed value must not be empty (RN07) |
| `description` | text | Optional |
| `addressLine` | varchar(255) | Optional, maps to `address_line` |
| `city` | varchar(120) | Optional |
| `state` | varchar(120) | Optional |
| `postalCode` | varchar(20) | Optional, no postal-code format rule in this feature |
| `country` | varchar(120) | Optional |
| `createdAt` | timestamptz | Required, default `now()` |

**Relationships**:

- `Venue` has many `Section` rows through `catalog.section.venue_id`.
- `Venue` may be referenced by `catalog.show.venue_id` with `ON DELETE RESTRICT`.

**Validation**:

- Create/update rejects blank or whitespace-only `name` with HTTP 400.
- Create/update duplicate `name` maps to HTTP 409 Problem Details.
- Delete is allowed only when no `Show` references the `Venue`; database restrict violations map to HTTP 409.
- Deleting a valid `Venue` cascades deletion of its `Section` rows.

## Section

**Table**: `catalog.section`

**Role**: Child entity describing the physical seating geometry within a `Venue`.

| Field | Type | Rules |
|---|---|---|
| `id` | UUID | Primary key, generated by PostgreSQL via `gen_random_uuid()` |
| `venueId` | UUID | Required FK to `catalog.venue(id)`, `ON DELETE CASCADE` |
| `name` | varchar(120) | Required, unique within the same `Venue` (RN11) |
| `numberOfRows` | int | Required, must be > 0 |
| `rowCapacity` | int | Required, must be > 0 |
| `capacity` | int | Read-only generated column: `number_of_rows * row_capacity` (RN12) |

**Relationships**:

- Belongs to one `Venue`.
- Is referenced logically by downstream inventory snapshots, but no cross-database FK exists.

**Validation**:

- Create/update requires existing `Venue`; missing venue returns HTTP 404.
- Create/update rejects blank section names and non-positive `numberOfRows`/`rowCapacity` with HTTP 400.
- Duplicate section name in same venue maps to HTTP 409.
- Payload input must not bind `capacity` into write commands; response DTOs expose it as read-only.

## Value Object: Address

`Address` is embedded in `Venue` as nullable columns:

| Field | Column | Rule |
|---|---|---|
| `addressLine` | `address_line` | Optional |
| `city` | `city` | Optional |
| `state` | `state` | Optional |
| `postalCode` | `postal_code` | Optional |
| `country` | `country` | Optional |

No CEP/postal-code format validation is part of US-CAT-10.

## Commands

### CreateVenueCommand / UpdateVenueCommand

- `name`: required, trimmed non-empty
- `description`: optional
- `addressLine`: optional
- `city`: optional
- `state`: optional
- `postalCode`: optional
- `country`: optional

### CreateSectionCommand / UpdateSectionCommand

- `venueId`: path parameter for create under a venue, immutable on update
- `name`: required, trimmed non-empty
- `numberOfRows`: required, integer > 0
- `rowCapacity`: required, integer > 0
- `capacity`: not present in command models

## State Transitions

`Venue` and `Section` do not have lifecycle status fields in this feature.

```text
Venue: absent -> active -> deleted
Section: absent -> active -> deleted
```

Updates keep the entity active. A deleted `Venue` removes child `Section` rows by cascade.

## Cache Keys

| Key | Value | Invalidation |
|---|---|---|
| `catalog:venue:{id}` | Venue detail including address and summary fields | Create/update/delete of the venue; section changes if detail embeds sections |
| `catalog:venue:{id}:sections` | Ordered/list response of sections for a venue | Create/update/delete of any section in the venue; delete of the venue |

## Error Mapping

| Case | HTTP | Problem Details title |
|---|---:|---|
| Blank Venue or Section name | 400 | `Validation failed` |
| Non-positive section geometry | 400 | `Validation failed` |
| Duplicate Venue name | 409 | `Venue name already exists` |
| Duplicate Section name in Venue | 409 | `Section name already exists for venue` |
| Venue/Section not found | 404 | `Resource not found` |
| Delete Venue referenced by Show | 409 | `Venue has scheduled shows` |
| Missing/invalid admin token | 401/403 | `Unauthorized` / `Forbidden` |
