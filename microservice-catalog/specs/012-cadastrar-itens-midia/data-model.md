# Data Model: US-CAT-12 - Cadastrar Itens de Mídia com Validação e Fallback

## MediaTypeCatalog (Tabela de Domínio Extensível)

**Table**: `catalog.media_type_catalog`

**Role**: Tabela de domínio seedada (não há API de escrita nesta feature). Consumida para validar `media_type_code` habilitado em `CreateMediaItemUseCase`. Inclusão de novos tipos (VIDEO, AUDIO) é operação de migração/seed de banco.

| Field | Type | Rules |
|---|---|---|
| `code` | varchar(30) | Primary key. Ex.: 'IMAGE', 'VIDEO', 'AUDIO' |
| `description` | varchar(120) | Required, NOT NULL |
| `enabled` | boolean | Required, default `TRUE`. Indica se tipo está ativo para novos cadastros |

**Seed Inicial (V1__init.sql)**:

```sql
INSERT INTO catalog.media_type_catalog (code, description, enabled)
VALUES ('IMAGE', 'Imagem promocional', TRUE);
```

**Validation (consumo)**:

- `CreateMediaItemUseCase` consulta `MediaTypeCatalogReaderPort.findByCodeAndEnabled(code)`:
  - Se `Optional.empty()`: tipo inexistente ou desabilitado → `InvalidMediaTypeException` → HTTP 400 RFC 7807.

## MediaItem (Entidade de Domínio / Aggregate Root)

**Table**: `catalog.media_item`

**Role**: Aggregate root para itens de mídia promocional. Contém URL cadastrada, tipo de mídia, status de fallback e chave lógica de cache/armazenamento.

| Field | Type | Rules |
|---|---|---|
| `id` | UUID | Primary key, generated by PostgreSQL via `gen_random_uuid()` |
| `mediaTypeCode` | varchar(30) | Required FK to `catalog.media_type_catalog(code)`. Maps to `media_type_code` |
| `url` | varchar(2048) | Required, globally unique via `uq_media_item_url`. Must match `^https?://` via `ck_media_item_url_scheme` (RN37) |
| `cachedFileName` | varchar(255) | Optional. Logical identifier / object storage key. Maps to `cached_file_name`. Default: `NULL`; set to `not_available.jpg` when `fallbackApplied = TRUE` |
| `fallbackApplied` | boolean | Required, default `FALSE`. Maps to `fallback_applied`. Set to `TRUE` when remote URL check fails/timeout (RN35, CA-CAT-03-MED) |
| `createdAt` | timestamptz | Required, default `now()`. Maps to `created_at` |

**Relationships**:

- Belongs to one `MediaTypeCatalog` via `media_type_code`.
- Is referenced optionally by `catalog.event.media_item_id` with `ON DELETE SET NULL` (RN05, mídia opcional).
  - Quando um `MediaItem` é excluído, o Postgres automaticamente zera `event.media_item_id = NULL` nos eventos vinculados. Nenhum código adicional é necessário na aplicação para a desvinculação.

**Validation**:

1. **Esquema de URL (prévio de domínio)**: `UrlValidator.isValidScheme(url)` rejeita esquema ≠ `http://` ou `https://` → HTTP 400 (`Esquema de URL inválido. Apenas http:// e https:// são aceitos.`)
2. **CHECK constraint banco**: `ck_media_item_url_scheme CHECK (url ~* '^https?://')` como lastro estrutural para bypass de API.
3. **Unicidade de URL (prévio de domínio)**: `MediaItemRepositoryPort.existsByUrl(url)` → retorno HTTP 409 (`URL já cadastrada.`)
4. **UNIQUE constraint banco**: `uq_media_item_url UNIQUE (url)` como proteção de concorrência simultânea; violações mapeadas para HTTP 409.
5. **Tipo de mídia habilitado**: inexistente ou `enabled = FALSE` → HTTP 400.
6. **Timeout check remoto**: 250 ms; estouro = `fallbackApplied = TRUE` sem falhar a criação (retorna 201).

## Commands

### CreateMediaItemCommand

- `mediaTypeCode`: required, varchar(30). Deve existir em `media_type_catalog` com `enabled = TRUE`.
- `url`: required, varchar(2048). Esquema `http(s)://`, única na base.

*Não há comando Update nesta feature* (a spec define apenas criação, consulta e exclusão).

### Queries

- GetMediaItemQuery: `id` UUID (cache-aside Redis primeiro, depois DB).
- ListMediaItemsQuery: `page` int base 0, `size` int (1-100, default 20).
- DeleteMediaItemCommand: `id` UUID. Sempre permitido (nunca 409 por vinculo a Event; SET NULL automático).

## State Transitions

`MediaItem` não possui lifecycle status explícito nesta feature (não há DRAFT/PUBLISHED). Estados implícitos:

```text
MediaItem: absent -> created (fallbackApplied = false OR fallbackApplied = true) -> deleted
```

- Quando URL remota é acessível: `fallbackApplied = FALSE`, `cachedFileName = NULL` ou opcionalmente cacheado (fora de escopo desta feature).
- Quando URL remota falha (qualquer status 4xx, 5xx, timeout, exceção de rede): `fallbackApplied = TRUE`, `cachedFileName = 'not_available.jpg'`.
- Delete: remove `MediaItem`; Postgres cuida do `SET NULL` em `event.media_item_id` automaticamente.

## Cache Keys

| Key | Value | TTL | Invalidation |
|---|---|---|---|
| `catalog:media-item:{id}` | JSON estruturado com `id`, `mediaTypeCode`, `url`, `cachedFileName`, `fallbackApplied`, `createdAt` | 3600s (configurável via `catalog.media.cache.ttl-seconds`) | **Síncrona** após sucesso de delete do `MediaItem` (DEL key). Após create, a chave pode ser preenchida lazy no primeiro GET. |

## Error Mapping (RFC 7807)

| Case | HTTP | Problem Details `title` |
|---|---:|---|
| Esquema URL inválido (não http/https) | 400 | `Esquema de URL inválido` |
| Formato URL malformado | 400 | `URL malformada` |
| `mediaTypeCode` inexistente ou desabilitado | 400 | `Tipo de mídia inválido ou inativo` |
| Campo obrigatório ausente (`url`, `mediaTypeCode`) | 400 | `Validation failed` |
| URL duplicada (check prévio ou constraint concorrente) | 409 | `URL já cadastrada` |
| `MediaItem` não encontrado | 404 | `Recurso não encontrado` |
| Token ausente/inválido em rotas admin | 401 | `Unauthorized` |
| Autenticado mas sem `ROLE_ADMIN` em escrita | 403 | `Forbidden` |
